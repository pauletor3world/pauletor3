Política de privacidade

pAuletOr 3 · atualizada em 15 de outubro de 2026

O que é o app

O pAuletOr 3 é um app desktop gratuito, usado por um grupo pequeno de amigos para jogar juntos no mesmo mundo de Minecraft. Ele não tem servidor próprio, anúncios nem coleta de dados para terceiros.

Acesso ao Google Drive

  • O app pede só a permissão drive.file. Com ela, ele só acessa os arquivos que ele mesmo criou no Google Drive da conta autorizada: a pasta do mundo, as versões salvas e as estatísticas do jogo.
  • Ele não lê, não lista e não altera nenhum outro arquivo do Drive.
  • A autorização é feita numa conta Google criada só para o mundo. O token de acesso fica guardado criptografado no computador de cada jogador (proteção de dados do Windows) e nunca é enviado para outro lugar.

Dados tratados

  • Arquivos do mundo de Minecraft, guardados no Google Drive da conta do mundo.
  • Nicks dos jogadores e tempo de jogo, para as estatísticas do grupo, guardados no mesmo Drive.
  • Mensagens para o Discord do grupo (por exemplo, "Fulano entrou no mundo"), enviadas só para o canal configurado pelo dono.
  • O endereço de rede privada (Tailscale) de quem hospeda, publicado no DuckDNS para os amigos encontrarem o servidor.

Compartilhamento

Nada é vendido nem compartilhado com terceiros. Os dados ficam entre os amigos do grupo e os serviços que eles mesmos configuraram (Google Drive, Discord, Tailscale e DuckDNS).

Como remover o acesso

Na conta Google do mundo, abra myaccount.google.com/permissions e remova o "pAuletOr 3". Para apagar os dados, exclua a pasta do mundo no Google Drive.
